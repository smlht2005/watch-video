# 畫面字幕 OCR vs Groq Whisper 轉錄：比較與做法

> 來源：2026-10-13／14 歸檔會性法師《大佛頂首楞嚴經》第103集（YouTube `kvsrMirvdDQ`，74 分鐘）時的實作經驗。
> 該片逐句燒入字幕，我用 OCR 把字幕全部抽出，與 Groq Whisper 逐字稿逐行比對校稿。

## 一句話結論

OCR 字幕**不能取代** Groq 轉錄，但拿來當**專有名詞的標準答案**非常有效。最佳做法是兩者互補：Groq 負責完整語音與時間戳，OCR 負責校正人名、書名、術語，兩邊有差異時以字幕為準，但保留 Groq 的口語。

## 比較

| 面向 | Groq Whisper 轉錄 | OCR 抽燒入字幕 |
|---|---|---|
| 適用範圍 | 任何有聲音的影片 | 只有畫面真的燒入字幕才行（沒有字幕就派不上用場） |
| 準確度 | 專有名詞、佛學詞誤聽多：圓通→遠通、葛藤→歌藤、阿難→歐南、照寮元→趙寮元、獅頭山→石頭山；這支校出數百處 | 文字基本是正確原文，人名、書名、引文都對（逗機、許止淨、徑山、古鼎） |
| 完整性 | 會整段漏轉（這支漏 17 分鐘，補漏時遇 HTTP 429）；片頭片尾會編出不存在的句子 | 無漏轉、無幻覺 |
| 忠實度 | 逐字還原口語（語助詞、口誤、重複），可去語助詞後保留 `transcript.raw.md` 原話 | 字幕是整理過的書面語：省略「呢啊」「注意哦」，會改寫句子，不是原話 |
| 時間戳 | 每句秒級時間戳，可直接進報告 | 取樣間隔 2 秒，只能對到約 2 秒；換行與跨句會對不齊 |
| 自身錯誤 | 同音字、斷句、簡繁 | 簡繁與同音混淆（眾→罪／累、異→昊、正脈→正服），「慍」常被丟掉；字幕本身也可能有錯，沒有第三來源可驗證 |
| 成本與速度 | 一次呼叫、數分鐘 | 74 分鐘取 2215 條字幕列，單程序約 1.8 秒一條，單程序要一小時以上（這次開 7 個程序平行） |
| 費用與隱私 | 要上傳音訊、會被限流（429） | 本機執行、免費，只吃 CPU |

## 這次的實際教訓

- 我先前靠上下文**推測**的專有名詞，有好幾個猜錯，都是字幕糾正的：趙寮元→**照寮元**、古頂→**古鼎**、晉山→**徑山**、徐子靖→**許止淨**、小繩→**小香**、投機→**逗機**、恭念→**一念**。校稿遇到不確定的專名，優先找畫面字幕，不要只靠上下文。
- 字幕不是原話，所以不要用字幕整句覆蓋逐字稿；只取差異處的用字，保留口語。
- OCR 輸出有簡繁／同音雜訊，每處差異要人工判斷，不能全自動套用。

## 做法（這次手工流程）

環境：Windows，OCR 用 [RapidOCR](https://github.com/RapidAI/RapidOCR)（`rapidocr-onnxruntime`）裝在獨立 venv，不動系統 Python。

1. 下載影片（`yt-dlp -f 136` 之類的 720p 視訊即可，不入庫）。
2. 切出字幕列：`ffmpeg -i video.mp4 -vf "fps=0.5,crop=iw*0.82:ih*0.18:0:ih*0.8" sub/s_%05d.png`（每 2 秒一張；crop 範圍依字幕位置調整，這支字幕在畫面下方，右側有直排標題要避開）。
3. 逐張 OCR，存成 `{秒數: 文字}` 的 JSON；CPU 吃重時可分成多個程序各跑一段。
4. 比對：把相鄰相似的 OCR 結果合併成字幕事件；逐字稿每一行（`[mm:ss] 文字`）找時間窗內的字幕，用 `difflib.SequenceMatcher` 算逐字稿字元被字幕涵蓋的比例；比例低於約 0.85 的列出來，人工逐段讀。
5. 人工判斷差異，整理成替換表（含上下文，避免誤傷）批次套用到 `transcript.md`，每段改完就 commit。
6. 摘要、投影片說明與 `meta.json` 裡出現的錯誤名稱要一併更新；`known_asr_errors` 記錄「字幕確認」與仍不確定的處理。

## 注意事項

- OCR 單張約 1–2 秒（CPU）。字幕變化不頻繁時，可只取字幕變化的畫面，約省一半時間。
- 比對腳本的「涵蓋比例」對短行、時間重疊行會誤報，低於 0.85 的行不必全部有問題。
- 暫存檔（`sub/` 圖片、OCR JSON、venv）放暫存區，不要進 repo；影片檔不入庫。
- Bash 的 `rm` 展開變數會被安全檢查擋，清暫存時改用字面路徑或 `"${VAR:?}"` 寫法。

## 可以改進的方向（尚未實作）

- 只對字幕變化的畫面做 OCR，並預設多程序平行。
- 直接輸出「逐字稿 vs 字幕」差異清單，作為校稿的第二輪輸入。
- 沒有字幕的影片：退回「Groq 兩次轉錄互補」；補漏遇 429 時，單獨重送缺漏段（見 `whisper.py` 的補漏流程與 issue #12／#13）。
