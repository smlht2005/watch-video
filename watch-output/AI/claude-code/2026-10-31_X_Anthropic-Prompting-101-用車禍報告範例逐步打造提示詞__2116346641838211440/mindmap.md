- Prompting 101 提示詞十要點
  - 開場與情境
    - 瑞典車險：表單＋手繪草圖
    - v1 極簡提示詞被誤判滑雪
  - 結構與迭代
    - 提示工程是實證科學
    - 任務→內容→指示→範例→重述
  - 1-2 任務與語氣
    - 說明角色與情境
    - 保持事實、有把握才判斷
  - 3 背景資料
    - 固定表單放系統提示詞
    - 可搭配 prompt caching
  - XML 組織資訊
    - 標籤標明內容性質
    - v3 判定 B 車有過失
  - 5-6 範例與對話歷史
    - few-shot 放灰色地帶案例
    - 歷史用於面向使用者應用
  - 7 重述任務防幻覺
    - 看不清就說看不清
    - 引用表單依據
  - 8 逐步思考（v4）
    - 先看表單再看草圖
  - 9 輸出格式（v5）
    - 判定包進 final verdict 標籤
  - 10 預填回應
    - 指定開頭，如 JSON 括號
  - 延伸思考
    - 用思考軌跡改進提示詞
