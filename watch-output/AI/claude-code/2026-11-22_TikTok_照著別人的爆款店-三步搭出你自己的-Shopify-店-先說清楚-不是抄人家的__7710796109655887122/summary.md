# 摘要：照著別人的爆款店，三步搭出你自己的 Shopify 店

**一句話**：講者（刀姐）主張用 Claude Code 照著參考店的截圖，三步搭出自己的 Shopify 店，學的是下單結構而非抄 logo／文案（講者主張，未查證）。

| 時間 | 重點 |
|---|---|
| 00:00 | Claude Design 進每個對話，Claude Code 也能用；強調不抄 logo 和文案 |
| 00:25 | 第一步：截下整條購買路徑（首頁、商品頁、購物車、手機版） |
| 00:30 | 第二步：在 Claude Code 開主題、丟截圖，拆 section 並換成自己的品牌商品 |
| 00:45 | 第三步：Shopify CLI 本地預覽，與原店並排截圖，讓它逐條修，約改兩三輪 |
| 01:02 | 結語：幫客戶看店先看購買路徑 |

## 名詞
- Claude Design：Claude 的設計功能（影片稱已放進每個對話）。
- Shopify CLI：Shopify 的命令列工具，可本地預覽主題。
- section：Shopify 主題中的頁面區塊。
