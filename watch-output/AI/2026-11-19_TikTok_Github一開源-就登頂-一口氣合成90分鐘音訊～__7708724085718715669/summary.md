# 摘要：SoulX-Podcast——一口氣合成 90 分鐘多人方言音訊的開源 TTS

**一句話重點**：講者介紹開源語音合成模型 SoulX-Podcast（畫面為 GitHub 專案頁）：可一口氣穩定輸出超過 90 分鐘音訊、支援多人多輪對話、普通話／英文／四川話／河南話／粵語，並能用標籤控制笑聲、嘆息、清嗓等副語言；講者稱發布首日登上 Hugging Face TTS 榜首（以上皆講者主張，未查證）。

## 名詞與縮寫

- **TTS**：文字轉語音（Text-to-Speech）。
- **零樣本（zero-shot）語音克隆**：不需針對該聲音額外訓練即可模仿。
- **副語言控制**：用標籤控制笑聲、嘆息、清嗓等非語言聲音。
