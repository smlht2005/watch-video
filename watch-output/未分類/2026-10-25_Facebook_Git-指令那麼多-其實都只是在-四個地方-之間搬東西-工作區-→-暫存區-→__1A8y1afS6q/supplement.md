第一部分 · 本機循環 （01–05 / 19）
  建立儲存庫、暫存、提交，

  08 git stash      把工作先收起來

第三部分 · 跨過網路 （09–11 / 19）
  在你和其他人的機器之間，
  搬動歷史。
  09 git push       發布本機歷史
  10 git fetch      下載，但不改動
  11 git pull       先抓取，再整合

第四部分 · 多條工作線 （12–16 / 19）

  13 git checkout     移動 HEAD
  14 git merge        合併兩段歷史
  15 git rebase       在新的基準上重播

第五部分 · 還原與追查 （17–19 / 19）
  把指標往回搬、用新提交抵銷，

  17 git reset   把指標往回搬

- 補充直接寫明（畫面直接寫明，講者沒唸）：各指令的編號與一句話說明、各部分副標、結尾提問「停一下，想想你今天最常會用到哪幾個指令？」。
