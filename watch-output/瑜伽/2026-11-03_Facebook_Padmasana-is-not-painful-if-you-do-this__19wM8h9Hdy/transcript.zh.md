# 蓮花坐不痛的做法（中譯）

```
[00:00] 教你怎麼做到蓮花坐（Padmasana），而且不會痛，也避免做蓮花坐時受傷。
[00:06] 首先，蓮花坐是個彎曲的姿勢，也就是膝蓋的姿勢。要記得膝蓋是屈戌（鉸鏈）關節，只能做彎曲和伸直。
[00:19] 所以蓮花坐看起來像是扭轉，很多人把腿抬起來，看起來像是膝蓋在動，其實那不是膝蓋的動作，而是直接來自髖關節。
[00:39] 記住，做蓮花坐時先這樣彎曲，確認膝蓋沒有扭轉；
[00:44] 然後把這條腿連同彎曲的部分，用力抓住這一側，先做這個蓮花坐的準備。
[00:51] 接著開始往前推，讓髖部伸展得更多。因為蓮花坐會對下背部、特別是薦骨造成很大壓力，
[01:00] 這種扭轉會讓你的髖部與臀肌做好準備，蓮花坐就會比較容易。至少停留五到十次呼吸，輕柔地感受伸展，你就準備好了。
[01:11] 換另一側，同樣的方式。先彎曲，確認沒有扭轉，把整條腿抱起放到另一側，抓住，然後單純扭轉。
[01:25] 扭轉時，不要只是把髖部抬起來，要讓髖部放下，再去扭轉。這樣就能伸展到後側臀肌。
[01:36] 這是第一步：先單純旋轉、放下；
[01:41] 要放得下去，代表你的鼠蹊（腹股溝）要有不錯的柔軟度。
[01:47] 下一個動作作為準備是蝴蝶式。做蓮花坐之前，蝴蝶式的動作非常、非常重要。
[01:53] 做蓮花坐有兩種方式：第一種是旋轉、彎曲；第二種是完全彎曲放下，再稍微把腳拉近，看看中間的空隙。
[02:13] 接下來換另一條腿，因為現在要把這隻腳放到另一條腿上面，這會產生一點扭轉。
[02:22] 有一個安全的做法：先壓住，然後把整條腿從下方抬起，
[02:31] 做髖臼（球窩關節）的內旋，來回擺動幾次，帶動整個髖部，然後放下。
```
