# 03: 影片筆記加入〈圖文對照〉

**What to build:** Obsidian 影片筆記在〈思維導圖〉之後加入〈圖文對照（畫面 + 逐字稿[＋中譯]）〉，內容來自 01 的共用函式：每段時間範圍、標題、說明、截圖與該段逐字稿。截圖縮到 1024 px 以內複製到 `_attachments/<video_id>/`，筆記用相對路徑。圖文貼文的圖文對照顯示「第 N 頁」，原本的〈圖文原頁〉區塊移除；`--with-pages` 保留但只印一次 WARNING。

**Blocked by:** 01（共用段落函式）、02（同一段筆記本文，接在其後避免衝突）

**Status:** ready-for-agent

- [ ] 筆記有〈圖文對照〉，位置在〈思維導圖〉之後、〈知識點〉之前，標題層級配合筆記結構
- [ ] 每段截圖指向 `_attachments/<vid>/` 的相對路徑，檔案存在且寬度 ≤ 1024
- [ ] 段落包含該段逐字稿；外語影片含中譯
- [ ] 沒有 slides 的資料夾以逐畫面方式產生圖文對照
- [ ] 圖文貼文用「第 N 頁」，沒有〈圖文原頁〉；`--with-pages` 只印 WARNING、不報錯
- [ ] 既有測試通過（carousel 頁面旗標相關斷言改寫為新行為）
