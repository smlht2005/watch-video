# watch-output 領域分類

**Status:** resolved（依現況補寫；已於 PR #26、#30 實作並合併）

## Problem Statement

歸檔的影片報告全部平放在同一層資料夾裡，數量一多（目前 25 支，主題橫跨 AI、佛學講座、理財、養生），就很難依主題找到想看的報告，索引也只是一張依日期排序的長表。第一版加入領域子資料夾後，領域名稱可以隨意輸入，打錯字（`Ai`、`佛学`）會悄悄多出一個新資料夾；「詞典 → 領域」的對應寫死在程式裡，新增詞典就得改程式；推測不出領域時也沒有任何提醒。

## Solution

每支影片歸檔到一個領域資料夾，領域只能是一份白名單裡的值。歸檔時可以明確指定領域；沒指定時沿用上次記住的值，再不行就由所選詞典推測，仍推測不出則放「未分類」並明顯警告。白名單外的值一律報錯，而且在下載影片之前就報錯。索引依領域分節，節內由新到舊，一眼看出每個領域有幾支影片。既有的平面資料夾可以一次批次搬進領域資料夾。

## User Stories

1. 身為歸檔者，我想把每支影片放進一個領域資料夾，以便依主題瀏覽報告。
2. 身為歸檔者，我想在歸檔時直接指定領域，以便分類不必事後再搬。
3. 身為歸檔者，我想讓重跑沿用上次的領域，以便更新報告時不用每次重打。
4. 身為歸檔者，我想在改變領域時讓資料夾自動搬到新領域，以便分類永遠與記錄一致。
5. 身為歸檔者，我想在沒指定領域時由所選詞典推測領域，以便常見主題（AI、佛學）不必手動分類。
6. 身為歸檔者，我想在推測不出領域時看到明顯警告並放進「未分類」，以便歸檔不中斷、但交付前記得分類。
7. 身為歸檔者，我想在領域打錯字時直接被拒絕並看到可用的值，以便不會悄悄多出錯誤的資料夾。
8. 身為歸檔者，我想讓英文領域只差大小寫時自動校正（`ai` → `AI`），以便不被無意義的錯誤打斷。
9. 身為歸檔者，我想讓簡體輸入（`佛学`）自動轉成繁體（`佛學`）並印說明，其他錯字（`佛教`）仍被拒絕，以便領域名稱一律是繁體中文且寫法唯一。
10. 身為歸檔者，我想讓打錯的領域在下載影片之前就報錯，以便不浪費下載與轉錄的時間與額度。
11. 身為歸檔者，我想在記住的舊領域已從白名單移除時被要求重新指定，以便不會被悄悄改成「未分類」。
12. 身為維護者，我想用一份白名單檔案管理所有領域，以便新增領域不必改程式。
13. 身為維護者，我想讓白名單同時決定索引的小節順序，以便順序只需維護一處。
14. 身為維護者，我想讓「未分類」永遠存在且排在最後，以便它不會被誤刪或排到前面。
15. 身為維護者，我想在每個詞典檔裡宣告它對應的領域，以便新增詞典時順便決定推測結果。
16. 身為維護者，我想讓測試檢查每個詞典宣告的領域都在白名單內，以便資料錯誤在合併前就被擋下。
17. 身為維護者，我想讓詞典宣告的領域不合法時在執行階段只警告並略過，以便一個資料錯誤不會讓歸檔失敗。
18. 身為歸檔者，我想在多個詞典推測出不同領域時以第一個詞典為準並看到說明，以便結果可預期且知道為什麼。
19. 身為讀者，我想讓索引依領域分節並在標題顯示數量（如「AI（12）」），以便一眼看出各領域規模。
20. 身為讀者，我想讓每節內由新到舊排列，以便最近歸檔的影片排在最上面。
21. 身為讀者，我想讓沒有影片的領域不出現在索引裡，以便索引不出現空表。
22. 身為讀者，我想讓索引連結指向領域資料夾裡的正確位置，以便點了就打開對的報告。
23. 身為維護者，我想讓索引每次都從各影片的記錄重建，以便索引不會與實際資料夾脫節。
24. 身為維護者，我想用一個整理指令把舊的平面資料夾批次搬進領域資料夾，以便既有歸檔一次就完成遷移。
25. 身為維護者，我想在整理指令裡用對照表覆寫個別影片的領域，以便批次修正分類。
26. 身為維護者，我想讓對照表裡只要有一個不合法的值就整批不搬，以便不會出現搬到一半的狀態。
27. 身為維護者，我想讓整理後的領域寫回每支影片的記錄，以便之後重跑沿用同一個分類。
28. 身為跨專案使用者，我想讓白名單跟著詞典目錄走，以便指向共用詞典目錄時領域設定一起帶過去。
29. 身為維護者，我想讓領域名稱維持中文，以便與既有的中文影片資料夾一致。
30. 身為維護者，我想維持只有一層領域、不建子領域，以便結構簡單，等單一領域超過約 30 支再考慮拆分。

## Implementation Decisions

- **一支影片只屬於一個領域**；跨領域的資訊交給關鍵字，不做多重分類或捷徑連結。
- **結構只有一層**：輸出根目錄底下是領域資料夾，再底下才是各影片資料夾；影片資料夾的命名規則不變。
- **領域白名單**是詞典目錄裡的一份獨立檔案（因為「身心生活」「商業理財」沒有對應詞典，無法從詞典推導）。目前的值與順序：AI、佛學、商業理財、身心生活、電子、雲端、未分類。白名單沒列「未分類」時自動補在最後。
- **決定領域的優先順序**：明確指定 > 影片記錄裡記住的值 > 第一個帶有合法領域宣告的詞典 > 「未分類」（附警告）。
- **繁體中文**：領域名稱有中文時一律用繁體，不用簡體；白名單本身由測試確保是繁體。
- **檢查規則**：完全符合才接受；英文只差大小寫，或簡體轉繁體後符合時，校正成白名單寫法並印說明；其他一律報錯，錯誤訊息列出可用值並提示到白名單新增。記住的值失效時，錯誤訊息要求重新明確指定。
- **檢查時機**：明確指定的領域在下載影片之前就檢查；記住的值與推測在歸檔寫檔階段決定。
- **詞典領域宣告**：每個領域詞典檔多一個領域欄位，取代原本寫在程式裡的對照表。宣告的值不在白名單時，執行階段印警告並略過該詞典；多個詞典推測不一致時取第一個並印出各詞典的推測。
- **影片記錄**新增領域欄位，重跑沿用；改變領域時歸檔流程會把既有資料夾搬到新領域（保留原始日期前綴，同時跟隨標題變動改名）。不在舊位置留轉址檔，外部連結失效可以接受，git 的改名歷史可追溯。
- **找既有資料夾**同時找領域資料夾裡的與舊的平面資料夾，讓遷移前後都能更新同一支影片。
- **索引**改為每次掃描所有影片記錄重建，不再逐列增刪：依白名單順序分節（白名單外的領域排在後面），節標題附數量，表格不再有「領域」欄，節內依最後更新日期由新到舊，空領域不輸出。
- **整理指令**：先替每個資料夾決定領域並收集所有錯誤；有任何錯誤就整批放棄並列出原因；全部合法才搬移、寫回記錄、重建索引。對照表的鍵可以是資料夾名稱或影片 ID。
- 領域名稱維持中文，Windows 環境依既有規則設定 UTF-8。

## Testing Decisions

- **好測試的標準**：只透過公開介面觀察外部行為（給定輸入得到的領域或錯誤、產生的索引內容），不檢查內部函式如何組合；預期值來自規格裡的實例，不在測試裡重算。
- **切入點一：決定領域介面**。輸入明確指定值、記住值、詞典清單與白名單，輸出領域或錯誤。涵蓋：優先順序、白名單外報錯、英文大小寫校正、簡體轉繁體、其他錯字仍報錯、記住值失效要求重新指定、多詞典不一致取第一個、推測不出得到「未分類」。
- **切入點二：重建索引介面**。在暫存輸出目錄放入幾份影片記錄後重建索引，檢查節的順序、節標題數量、節內由新到舊、空領域不輸出。
- **切入點三：詞典資料檢查**。逐一確認領域詞典宣告的值都在實際的白名單內，白名單最後一項是「未分類」，且白名單每個值都是繁體中文（簡轉繁後不變）。這驗證的是資料，不是程式。
- **手動驗收**：最高層切入點是整支歸檔命令列，但它需要下載影片，不放進自動測試；改以手動確認「打錯的領域在下載前就報錯並列出可用值」，已實測通過。
- **先例**：既有測試已用暫存目錄加替換輸出根目錄的方式測「依影片 ID 找資料夾」，索引測試沿用同一做法；語言判斷、詞典替換等測試同樣是純函式輸入輸出的寫法。

## Out of Scope

- 一支影片屬於多個領域、捷徑或符號連結。
- 子領域（兩層以上的資料夾結構）。
- 英文代號式的領域名稱。
- 搬移資料夾後在舊位置留轉址檔。
- 每個領域資料夾各自的索引檔。
- 由影片內容自動判斷領域（只由詞典宣告推測）。
- 修正外部對舊路徑的引用。
