# 01：分段、續跑、合併（核心）

**What to build:** `subtitle_ocr.py run --segment-min N` 把影片切成每 N 分鐘一段，每段辨識完以原子寫入存成 `<seg-dir>/seg_<起始秒>.json`；重跑時跳過已存在的段落；全部完成後合併成 `--out`（格式 `{秒數: 文字}`，與現行相同）。缺段時不寫 `--out`、列出缺哪幾段並以非 0 結束。不加 `--segment-min` 時走原本一次跑完的路徑。分段入口函式可注入「取得影片長度」與「辨識一段」兩個替身。

**Blocked by:** 無

**Status:** ready-for-agent

- [ ] 段落邊界正確：段長取 `--every` 的倍數，最後不足一段照常處理，`--start`／`--end` 仍有效
- [ ] 合併結果與一次跑完等價（取樣點相同、無遺失或重複）
- [ ] 已存在的 `seg_*.json` 視為完成並跳過；暫存檔 `.tmp` 不算完成
- [ ] 缺段時不寫 `--out`，印出缺的段落，結束碼非 0
- [ ] 不加 `--segment-min` 時行為與現在完全相同，既有測試不變
- [ ] 測試涵蓋以上，使用注入的替身（不連 ffmpeg／RapidOCR）
